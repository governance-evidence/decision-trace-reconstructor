# Paper23 typed-contract retrospective replay

This offline development replay is authorized on 2026-10-11. It retains all 72 projected V5 packets, 504 question judgments, 432 property references, 36 paired trajectories and the original baseline. The V5 assessor is not rerun, re-prompted or relabelled. No API or credential is used. No population confidence interval is reported.

The primary descriptive endpoint is full-versus-non-full agreement with frozen V5 references, using the existing crosswalk, metrics and paired-deletion functions. Predictions are evaluated under two distinct contracts: repaired structural coverage on the unchanged historical adapter, and decision-evidence-v1 on paper23-typed-adapter-v1. Old DTR v0.1.0 predictions are copied from frozen rows and verified against the same reference and baseline. Contract differences make this a compatibility and regression analysis, not a common-target accuracy contest or independent validation.

The typed projection selects material commit/refusal attempts; read-only inspect_state calls acquire evidence and are not material attempts requiring human approval. Exact client echoes are not extra executor observations. Every original record, inclusion decision and normalized field is retained in a projection audit. Unknown record kinds, malformed read calls or unmatched/conflicting client results refuse processing. Producer identities and timestamps remain unchanged. Roles reflect record provenance, not actor spelling; executor is also the name of a model actor in the two-agent protocol, so producer-role conflicts remain visible and are not extra agents. Observer distinctness is logical identity only, not organizational or process independence.

Permitted normalizations are tool descriptor names, singleton resource scope lists, prompt content, explicit state entity identifiers, state-to-actual_state, unique receipt-to-call target joins, and human approval joins requiring both exact request hash and parent call ID. No grant tools/resources, action policy version, target for a targetless refusal, receipt actual_state or final after_call_ids is supplied from context, other packets, model prose, deleted evidence or reference labels. Present but insufficient fields must remain insufficient. Original model/refusal mistakes remain in the data.

The typed contract was developed after seeing V5. Its 20-case authored development challenge is not new independent evidence; its frozen results remain separate. Some strict obligations were never recorded by the original harness. Disagreement with V5 therefore cannot by itself establish either instrument's correctness. Prospective typed capture and independent adjudication remain necessary for general validity claims.

Before scoring, freeze code, protocol, the entire V5 directory and prior V4/V5/challenge archive hashes. Snapshot current reconstructor source and replay/helper modules. Refuse an existing result directory. Recheck hashes after scoring. Report failures and every property, including non-full reasons. Preserve all predecessors; write only a separate replay directory.
